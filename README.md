# Listening Lab

Web luyện nghe tiếng Anh với hai chế độ, một file HTML duy nhất (không cần build):

- **Dictogloss**: đọc script, nghe dò theo script, bóc từ khoá bằng kéo thả hoặc tự điền, nghe dò lại.
- **Dictation (chép chính tả)**: nghe từng câu, gõ lại, lặp câu và chờ giữa các lần.

Có 5 giao diện (Chòm sao, Lego, Khuông nhạc, Đại dương, Mây cầu vồng), Mochi, combo, XP và màn thưởng.

## Chạy
Mở `index.html` trong trình duyệt, hoặc bật GitHub Pages cho repo (Settings → Pages → Deploy from a branch → `main` / root).

## Lưu ý
- Hiện dùng giọng đọc của trình duyệt (Web Speech API). Bản dùng audio thật sẽ được thêm sau.
- Bài do giáo viên soạn chỉ lưu trong trình duyệt (localStorage) khi chạy ngoài Claude.
- Font tải từ Google Fonts nên cần có mạng.
